# Промо Tattoo House для Reels

Відео 24 с, 1080×1920, 30 fps, без звуку. У ньому справжні сторінки сайту (`../index.html`, `gallery.html`, `booking.html`, `masters.html`) у `<iframe>`, нічого не перемальовано.

## Записати відео

```bash
node promo/record.mjs
```

Результат: `promo/out/tattoo-house-promo.mp4` (H.264, yuv420p, faststart). Запис займає ~1,5 хв. Сервер `serve.py` скрипт запускає сам, на порту 8790.

Потрібні Node 22+, Google Chrome, Python 3 і ffmpeg. Без ffmpeg кадри збережуться в `promo/out/frames/`, а скрипт надрукує команду для склейки.

Додаткові параметри:

| Параметр | Що робить |
|---|---|
| `--stills 2,6.5,13` | лише PNG-кадри на цих секундах → `promo/out/stills/` |
| `--live` | дані з Supabase замість стартових (`lib/seed-data.js`) |
| `--out ~/Desktop/reel.mp4` | інший файл результату |
| `--port 8791` | інший порт, якщо 8790 зайнятий |

За замовчуванням записувач віддає сайту порожній `config.js`, тому в кадрі стартові дані. Так у відео не потрапляють тестові значення з бази.

## Подивитися без запису

```bash
python3 serve.py
```

- http://localhost:8000/promo/ — прев'ю по колу; пробіл ставить на паузу, стрілки йдуть на кадр уперед/назад, Shift + стрілка на секунду.
- http://localhost:8000/promo/?t=18.5 — точний стоп-кадр.

Прев'ю бере живі дані з Supabase (як сайт) і грає в реальному часі, тому може трохи відрізнятися від запису. У відео кожен кадр рендериться точно на свою секунду.

## Змінити тексти і нік

Обʼєкт `PROMO` на початку `promo/promo.js`:

```js
nick: '@_volodimir_23_',
title: 'Замовляйте | у~мене *сайт',   // «|» новий рядок, «~» нерозривний пробіл, «*слово» червоне
sub: 'Пишіть у~директ',
cta: 'Написати',
tilt: 'random',                       // нахил наклейки-лого або число в градусах
captions: { ... }                     // підписи над і під вікном
```

Після зміни запустіть `node promo/record.mjs` ще раз.

Фінал зверстаний під тексти приблизно такої ж довжини: заголовок у 2 рядки (до ~11 літер у рядку), нік до ~20 символів, кнопка 1–2 слова. Довший текст наїде на сусідні рядки: перевірте `node promo/record.mjs --stills 23` перед повним записом.

## Як це влаштовано

- `promo.render(t)` малює момент `t` секунд: GSAP-таймлайн (`tl.time(t)`) плюс доріжки курсорів, скролу, hover і кліків.
- У режимі запису годинники всередині iframe віртуальні: `setTimeout`, `requestAnimationFrame` і CSS-анімації сайту йдуть рівно по 1/30 с на кадр.
- Hover сайту відтворено класом `.ph`: правила з `:hover` копіюються з `style.css` автоматично.
- Логотип фіналу: `promo/assets/logo.png` (зменшена копія `фото/logo.png`, бо `фото/` не в git).
